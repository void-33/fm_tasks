## Overview

DarkStream is a streaming speech-synthesis model for real-time speaker anonymization. It
factorizes speech into speaker-independent content and speaker identity, then re-synthesizes
the waveform with a GAN-sampled pseudo-speaker identity, so the output cannot be linked back
to the source speaker while remaining intelligible.

### Core Components
- **Content Encoder:** Causal CNN + lookahead + causal self-attention → 512-d linguistic embeddings
- **k-means Bottleneck:** Optional 256-centroid quantization to strip residual speaker cues
- **Speaker Encoders:** X-vector + ECAPA-TDNN (concatenated) for real-speaker conditioning during training
- **Pseudo-Speaker Generator:** WGAN-QC that synthesizes anonymized 704-d speaker embeddings
- **Speaker/Variance Adapter:** AdaIN/FiLM conditioning + F0/energy predictors
- **Decoder:** Causal MHSA context layer + HiFiGAN-style causal upsampling vocoder (direct waveform output, no mel step)

## Module A: Content Encoder

**Role:** convert raw waveform → speaker-independent linguistic embedding.

**Training supervision:** cross-entropy against pseudo-labels from k-means (N=200) over
HuBERT-base layer-9 features (Fig. 1a).

**Two front-end variants:**
| Front-end | Detail |
|---|---|
| Raw waveform (default) | HiFi-derived causal CNN, 1 residual block, kernel 5, dilations [[1,1],[3,1],[5,1]], downsample [2,4,5,8] → ÷320, 512-d @ ~20ms/frame |
| Mel-spectrogram (alt.) | 160-bin mel (16kHz, 1024 FFT, 320 hop) → lightweight ConvNeXt encoder (layers [1,1,3,1]) → 512-d @ 20ms/frame |

**Lookahead layer:** 1D conv, non-causal, receptive field up to 280ms into the future — lets
the encoder anticipate coarticulation without full-utterance delay.

**Contextual layer:** 8 causal multi-head self-attention layers, fixed 2-second past window,
ring KV cache (zero-initialized, fills over 2s).

**Selected operating point:** 140ms lookahead + contextual layer — captures ≈99% of
non-causal token accuracy within the 350ms latency budget (Table I).

---

## Module B: k-means Bottleneck

Quantizes the 512-d content embedding against a 256-centroid codebook learned post-hoc
(freeze content encoder → run k-means → codebook → fine-tune decoder 300k extra steps).

Effect: removes residual speaker leakage from the content stream at the cost of ~2–20pp
higher WER depending on lookahead (Table IV) — the main privacy/quality knob alongside α
in comparable systems.

---

## Module C: Speaker/Variance Adapter

**Speaker embedding source (training):** concatenation of noise-robust X-vectors and
context-sensitive ECAPA-TDNN embeddings.

**Conditioning mechanism:**
```
content_norm = InstanceNorm(content_embed)                 # strip residual speaker cues
γ, β = Conv1D_γ(speaker_embed), Conv1D_β(speaker_embed)     # causal, frame-level
adapted = γ ⊙ content_norm + β                              # AdaIN / FiLM re-coloring
```

**Prosody heads:** two lightweight blocks (2-layer causal CNN, kernel=3, ReLU, LayerNorm,
dropout, pointwise conv) predict F0 and energy trajectories, supervised with ground truth
in training; at inference these predictions are injected directly into the feature stream.

---

## Module D: Decoder / Vocoder

1. **Context layer:** causal MHSA block identical in spirit to the content encoder's, 2-sec
   look-back, adds long-range temporal coherence to the speaker-adapted embedding sequence.
2. **Waveform generator:** HiFiGAN-style, causal transposed convolutions, upsample rates
   [8, 5, 4, 2], residual blocks (kernel 5, dilations [[1,1],[3,1],[5,1]]) → 16kHz audio.
3. **Losses:** mel-spectrogram reconstruction + multi-scale/multi-period waveform
   discriminators + multi-resolution spectrogram discriminator (same discriminator family
   as RVQGAN [20]).

No intermediate mel-spectrogram is generated at inference — waveform is produced directly,
which is the paper's stated latency optimization over cascaded codec approaches.

## Module E: Pseudo-Speaker Generator (GAN)

**Architecture (WGAN-QC, quadratic transport-cost critic):**
```
Generator G:
  z (16-d noise) → Linear → 192-d → reshape 3×8×8
  → 2× ResNet blocks (3×3 convs, residual)
  → 2 stages of [2× upsample + ResNet blocks]
  → 2 final ResNet blocks
  → flatten → Linear → 704-d pseudo-speaker embedding

Critic D:
  704-d → Linear → reshape 3×8×8
  → 2× ResNet blocks
  → 2 stages of [2× avg-pool downsample + ResNet blocks]
  → flatten → Linear → scalar score
```

**Training objective (Eq. 1 in paper):**
```
L_D = E[D(e_real)] − E[D(G(z))] + 10 · E[(‖∇ê D(ê)‖ − 1)²]     (gradient penalty, λ=10)
L_G = −E[D(G(z))]
```

**Inference-time rejection sampling:** draw `e_syn = G(z)`; reject and resample if
`cos_sim(e_syn, e_orig) ≥ 0.65`, guaranteeing the anonymized identity is both realistic and
sufficiently dissimilar from the true speaker.

---

## Mathematical Formulations

**AdaIN/FiLM conditioning:**
```
h' = γ(s) ⊙ InstanceNorm(h) + β(s)      where s = speaker embedding
```

**k-means quantization (content bottleneck):**
```
q(x) = argmin_{c_i ∈ C} ‖x − c_i‖²,   |C| = 256
```

**WGAN-QC objectives:** see Module E above.

**Rejection sampling criterion:**
```
accept G(z) iff cos(G(z), e_orig) < 0.65
```

## Performance Metrics

### Latency (60ms chunk, RTX 3090, wave+CL front-end)

| LA (ms) | Encoder-only (ms) | End-to-end (ms) | Non-streaming RTF |
|---|---|---|---|
| 0   | 69.9  | 84.3  | 0.005 |
| 140 | 189.3 | 203.0 | 0.005 |
| 280 | 309.3 | 322.9 | 0.005 |

CPU RTF (wave+CL): **0.258** (~4× faster than real time).

### Linguistic accuracy (token-ID top-1, %)

| LA (ms) | Wave | Wave+CL | Mel | Mel+CL |
|---|---|---|---|---|
| 0   | 53.16 | 66.32 | 56.32 | 57.83 |
| 140 | 63.77 | 78.99 | 76.90 | 77.74 |
| 280 | 67.94 | 79.69 | 77.75 | 78.54 |

### Utility & privacy, no quantization (140ms LA, wave+CL)
- WER: **2.09%**
- Emotion UAR: **65.31%**
- EER lazy-informed: **12.10%**
- EER semi-informed: **6.90%**

### Utility & privacy, with 256-centroid k-means quantization (140ms LA, wave+CL)
- WER: **9.52%**
- Emotion UAR: **34.49%**
- EER lazy-informed: **46.75%** (near chance)
- EER semi-informed: **22.68%**

## Known Limitations (from paper's Discussion)

1. Does not explicitly disentangle static traits (accent, age, sex) from dynamic ones
   (emotion, speaking style) — some indirect identity cues may survive.
2. k-means quantization that maximizes privacy also causes the largest MOS drop (3.22).
3. No public reference implementation — this document is a reconstruction, not a source
   audit.
